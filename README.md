## 🚀 Quick Install

Run the automated installer to set up dependencies, back up existing configs, and symlink the dotfiles:

```bash
# Clone the repository
git clone https://github.com/Icefox0312/hyprland-dotfiles.git
cd ~/hyprland-dotfiles

# Make the installer executable & run
chmod +x install.sh
./install.sh
